## THE BUG (блокер, translation-gy3)

**Symptom**: прогон фикстуры падает до первого вопроса. Три попытки подряд:
```
[dependency-graph-proposal attempt 1/3] failed (NETWORK_ERROR): fetch failed
[dependency-graph-proposal attempt 2/3] failed (NETWORK_ERROR): fetch failed
[dependency-graph-proposal attempt 3/3] failed (NETWORK_ERROR): fetch failed
```
Полный лог: `scratchpad/diag/head-baseline-run.log`

**Error Output**:
```
TypeError: fetch failed
  at callAnthropic (src/lib/ai/chat-provider.ts:1004)
  at runCompletionAttempt (src/lib/ai/chat-provider.ts:1146)
  at createChatCompletionDetailed (src/lib/ai/chat-provider.ts:1272)
  at structured (src/lib/ai/structured-output.ts:366)
  at withStructuredRetry (scripts/run-aurora-fixture.ts:725)
  at runStage (src/lib/knowledge/dependency-graph-builder.ts:184)
  at ensureDependencyGraph (scripts/run-aurora-fixture.ts:1783)
  at reuseExtractionRun (scripts/run-aurora-fixture.ts:2522)
[cause]: SocketError: other side closed { code: 'UND_ERR_SOCKET' }
```

**Root Cause** (установлено, подтверждено официальной спецификацией Anthropic API):
`postAnthropicMessages` в `src/lib/ai/chat-provider.ts:948-966` отправляет **непотоковый** запрос — в теле есть `max_tokens`, но нет `stream: true`. Вызов идёт с `maxTokens = 16_000` (`scripts/run-aurora-fixture.ts:1673`, константа `DEPENDENCY_GRAPH_STAGE_MAX_TOKENS`) на модели `claude-sonnet-5` с промптом на все 45 unit'ов.

Спецификация Anthropic прямо требует стриминг: «Stream for `max_tokens > ~16K` (all models). Non-streaming requests hit SDK HTTP timeouts at high `max_tokens`». Отягчающий фактор: на **Claude Sonnet 5 отсутствие поля `thinking` означает, что adaptive thinking ВКЛЮЧЕНО по умолчанию** (в отличие от Sonnet 4.6, где отсутствие поля значило «без размышления»). Запрос сначала долго думает, потом генерирует до 16k токенов — всё в одном непотоковом HTTP-ответе. Сервер закрывает соединение.

**Почему повторы не спасают**: все три попытки упираются в ту же стену. Это не транзиентный сбой сети — канал исправен (`curl https://api.anthropic.com/v1/models` отвечает 200 за 2 секунды).

### Investigation Done
- Проверена связность с api.anthropic.com — HTTP 200, 2.1s. Дело не в сети вообще.
- Прогон умер, потратив **$0.00** — три попытки без usage, `scratchpad/head-baseline-2026-08-11/run-summary.json` подтверждает `totalUsd: 0`.
- В `chat-provider.ts:1364-1440` **уже есть** потоковый путь `streamProviderTokens` с `stream: true` и разбором SSE. Это готовый парсер для переиспользования.
- Тот же механизм объясняет Q07/Q08 в прогоне v3 (`fetch failed` на query-frame).

### Fix Approach
Перевести путь `structured()` / `createChatCompletionDetailed` на стриминг, **переиспользовав существующий SSE-парсер**, а не написав второй (правила проекта: «No Shadow Systems», «One Utility for Policy Logic»).

Проектное решение, которое принимаешь ты: включать стриминг всегда для этого пути или по порогу. Аргумент против порога: наш вызов ровно на границе 16 000, порог «больше 16k» его бы не поймал.

Обязательно сохранить при переходе: `attempts[]` телеметрию, `usage` (включая `cache_read_input_tokens`), `stop_reason`, и учёт стоимости в ledger (`src/lib/ai/cost.ts`, `src/lib/ai/call-trace-log.ts`). Ledger считает реальные деньги — сломать его нельзя.

**Начни с падающего теста** с замоканным transport'ом. Прогон против живого провайдера для проверки этого не нужен и не разрешён до готовности.

## ARCHITECTURE & FLOW

```
DOCX
 └─> извлечение знаний (LLM, батчами)
      └─> аудит покрытия ──> точечный ремонт ──> повторный аудит
           └─> ЗАМОРОЖЕННЫЙ АРТЕФАКТ (phase=COMPLETE, 45 units, 45 embeddings)
                └─> [вопрос]
                     ├─ QueryFrame builder        (query-frame)

                     ├─ реранкер                   (reranker)
                     ├─ decision-relevance классификатор
                     ├─ resolution / применимость
                     ├─ синтез ответа              (synthesis)
                     ├─ challenge-compatibility    (проверка отброшенных кандидатов)
                     ├─ condition-preservation     (условия не потеряны?)
```

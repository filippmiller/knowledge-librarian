## PHILOSOPHY & DECISIONS

| Решение | Обоснование | Отвергнуто |
|---|---|---|
| Замер всегда проходит, приёмка требует чистого прогона | Десять фатальных дверей делали систему неизмеримой; вероятность пройти = произведение вероятностей стохастических судей | Ослабить сами гейты — это скрыло бы дефекты |
| Стадии принимают реестр **параметром** | Не передан → прежнее фатальное поведение; обратная совместимость и тесты целы | Глобальное «больше не падать» |
| При провале taint-resample берём **замену**, не оригинал | Оригинал заражён текстом оракула → завысил бы счёт. Замена лишь неполна | Оставить оригинал — испортило бы валидность замера |
| Правила таксономии — один модуль на три промпта | 4 из 6 сбоев были расхождением статических текстов, не ошибками модели | Продолжать точечные фиксы по одному промпту |
| Описания фактов — **критерий**, не перечень мест | Перечень из фикстуры = подгонка под неё; для апостиля/станков бесполезен | Перечислить «транспорт, очередь, общий стол» (была такая редакция, отвергнута владельцем) |
| Не дообучать LLM на своих данных | Источник #1 (Microsoft): fine-tune для **stable content**, RAG для **dynamic**. Прайсы меняются. Плюс fine-tune не даёт цитат и аудита | «Обучить свою нейросеть» |

### МОИ ОШИБКИ — НЕ ПОВТОРЯЙ

1. **Оптимизировал прокси вместо метрики.** 7 прогонов ушло на то, чтобы аудиторы извлечения замолчали. Когда замолчали — грейдер всё равно нашёл непокрытые группы. Чистый аудит ≠ хороший ответ.
2. **n=1 атрибуция.** «b8 прошёл» после одного прогона — не доказательство. Разброс виден: taint-resample брал 2 попытки в одном прогоне и 3 в другом.
3. **Тесты промптов — иллюзия защиты.** «Промпт содержит строку X» проходит, даже если модель правило игнорирует. Тест `b7 one-to-many numeric repair` не поймал `translation-dza`, потому что его mock уже возвращал правильный ответ. Нужен replay-слой на записанных ответах живой модели.
4. **Диагностику по чекпойнту нашёл на 5-м прогоне, `--reuse-extraction` — на 8-м.** Обе были доступны с самого начала.
5. **Шлифовал `privacyContext` через час после того, как сам установил, что все пять фактов подлежат замене.** Владелец справедливо это назвал.

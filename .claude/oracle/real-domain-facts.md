**Дата сборки:** 2026-08-12
**Назначение:** это НЕ набор вопросов оракула. Это проверяемая фактическая база, против которой вопросы будут оцениваться. Владелец должен её валидировать.
**Правило маркировки:** каждый факт помечен `[VERIFIED: <путь> + где]` или `[UNCERTAIN: почему]`. Ничего, помеченного VERIFIED, не додумано — за ним стоит дословная цитата. Всё, что я вывел сам, помечено UNCERTAIN или вынесено в §F «Пробелы».

**Уровни источников** (важно для разрешения споров):
- **S1 — первичный документ компании** (`.docx` в репозитории). Читается напрямую, текст извлечён.
- **S2 — разбор «тетради стажёра»** (`docs/bot-audit/04-trainee-notebook.md`). Сам PDF в репозитории отсутствует; разбор сделан визуально по страницам. Тетрадь по её собственному статусу **первична** по отношению к правилам, извлечённым из инструкций поштучно.
- **S3 — дамп продовой базы знаний** (`tmp-upload/apostille-report.txt`): правила `R-N`, QA-пары, чанки. Чанки = исходный текст документа, **правила = пересказ LLM и могут противоречить своей же цитате** (см. §D).
- **S4 — вывод бота / черновик аудита.** Не источник. Используется только как объект проверки.

## F. Пробелы: чего нет ни в одном источнике

Отсортировано по стоимости ошибки.

1. **Нет правила «что делать, если документ выдан в другом регионе РФ».** База уверенно говорит **где нельзя**, но нигде не говорит **что предложить вместо**. Проверены подстроки `другом городе`, `другого региона`, `иногород`, `Саратов`, `ГИАЦ` — по регионам РФ ноль содержательных попаданий. Есть шаблон для заграницы (РБ — через доверенное лицо) и для Москвы/МО (партнёр Олег), но **нет партнёрской схемы для произвольного региона РФ** и нет правила «регионы кроме СПб/ЛО/МСК/МО не обслуживаем». `[VERIFIED как пробел: docs/bot-audit/blind-test-son-saratov.md §3.1]`

2. **Нет связки «справка из другого региона → продать новую СОН с апостилем».** Услуга с ценами есть (35 400 ₽ и т.д.), правило «новая справка нужна при срочности» есть — про регион ни слова. **Нигде не сказано, в каком регионе партнёр получает новую СОН**, то есть решает ли эта продажа проблему региона вообще. Менеджер (и бот) может продать услугу, которая не сработает. `[VERIFIED как пробел: blind-test-son-saratov.md §3.2]`

3. **Не разрешён вопрос про НКО как обходной путь для чужого региона** (§D.5). Четыре правила формально противоречат друг другу; прямого ответа нет.

4. **Нет адресов и контактов офисов самой компании «Аврора».** `Чек лист для справки вуз[1].docx` заканчивается пустыми заголовками «Адреса:» и «Контакты:». Вопрос «Какие у вас офисы в Санкт-Петербурге?» дал **8 эскалаций** с ответом «В базе знаний нет данных». `[VERIFIED: documents\Чек лист для справки вуз[1].docx, конец файла + docs/bot-audit/00-diagnosis.md:54]`

5. **Не указано, входит ли госпошлина 2500 ₽ в клиентскую цену.** Поиск `пошлина включена` даёт попадание только для нострификации. Менеджер не может сказать «итого 5000 ₽ и больше ничего» без риска. `[VERIFIED как пробел: blind-test-son-saratov.md §3.4]`

5а. **Нет ни одного факта о странах СНГ и правовой помощи.** Ни один документ не отвечает, нужен ли апостиль для Казахстана, Белоруссии, Армении, Узбекистана и т.д. — при том что это самый частый клиентский профиль бюро (см. молдавскую инструкцию и миграционные услуги). Единственное упоминание Казахстана в корпусе — миграционное основание для ВНЖ.

6. **Нет списка стран Гаагской конвенции.** Все инструкции требуют «проверить, входит ли страна в Гаагскую конвенцию», но самого списка в корпусе нет — есть только обратный список 86 стран, которым нужна КЛ. Отсутствие страны в этом списке ≠ членство в конвенции. Отдельно упоминается группа «Израиль, Финляндия, Германия, Испания, Португалия, Италия» с особой схемой / двойным апостилем (`Апостиль_страны_кому_на_оригинал_кому_двойной`) — **файла в репозитории нет**.

7. **Нет прайсов как файлов.** Ни `Прайс клиентский апостиль… 010126`, ни `Прайс внутренний… 010125`, ни `Прайс на перевод и заверение-010126`. Все цены услуг (в отличие от госпошлины) держатся на цитатах правил через `docs/bot-audit/`. Тарифы на сам перевод (~1500 значений) вдобавок не имеют разрешённой границы между 2 и 3 категорией сложности — **цену перевода нельзя назвать автономно ни боту, ни человеку**. `[VERIFIED: docs/bot-audit/06-price-table-and-source-routes.md §1 «Чего сознательно не сделано»]`

8. **Отсутствуют три ключевых `.docx`** по апостилю (МинЮст, ЗАГС, ЗАГС ЛО) и `Инструкция по оформлению Апостиля в МВД`. Пока их нет, любой факт по МЮ/КЗАГС/ЛО опирается на фрагментарные чанки, а по МВД СПб — вообще на пересказ.

9. **Нет `тетрадь стажера.pdf`.** Текстовый слой есть только на 5 страницах из 12; при импорте в базу 7 страниц потерялись бы. Самый структурированный источник компании существует в репозитории только в виде пересказа.

10. **Нет правила «сколько живёт апостиль / срок годности справки».** Ни один документ не отвечает, сколько действительна СОН или апостилированный документ — типовой клиентский вопрос.

11. **Нет сценария `apostille.mvd`.** Существуют `apostille.zags.spb` (97 правил), `apostille.zags.lo` (49), `apostille.min_justice` (101), `apostille` (8) и 1468 правил с `scenarioKey = null`. Вся ветка МВД лежит в общей куче — сценарная фильтрация на самом релевантном корпусе отключена. `[VERIFIED: blind-test-son-saratov.md §3.7]`

12. **Нет расшифровки «форма 6» и других форм ЗАГС.** Руководитель на этот вопрос отвечает «гуглить». `[VERIFIED: sample\Вопросы менеджеров.xlsx]`

});" "documents/шпаргалка про апостили.docx"
